# ميزان

تطبيق إسلام لإنقاص الوزن: سعرات يومية، دفتر أكل بالأكلات الفلسطينية، الماء، الخطوات من Health Connect، تمارين البطن والخواصر، منحنى الوزن، مستشار يحلل صورة الأكلة، وتنبيهات عند التقصير.

## تنزيل التطبيق
من صفحة **Releases** نزّل آخر ملف `mizan-v1.X.apk` وثبّته.
كل تعديل يُرفع على `main` يبني نسخة جديدة تلقائياً، وتتثبت فوق القديمة بدون ما تضيع بياناتك.

## الملفات
- `app/src/main/assets/www/index.html` واجهة التطبيق كاملة
- `MainActivity.kt` الواجهة + الكاميرا + الربط مع Health Connect
- `ReminderWorker.kt` التنبيهات كل ساعة
